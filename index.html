本アプリのデプロイおよびGoogle APIキーの発行ステップガイド

ステップ 1: GitHub Pages で最短5分で無料公開

  1. GitHubで新しいリポジトリを作成（例: ai-workspace-copilot, Publicに設定）。
  2. このコードを index.html という名前で保存し、リポジトリにコミット/プッシュ。
  3. リポジトリの Settings > Pages タブを開く。
  4. Source を Deploy from a branch にし、Branch を main (/root) に指定して Save。
  5. 数分で https://<ユーザー名>.github.io/ai-workspace-copilot/ が発行され公開完了！

ステップ 2: Groq API Key の無料取得

  1. Groq Console (console.groq.com) にアクセスしアカウント作成。
  2. 「API Keys」セクションで Create API Key をクリック。
  3. 発行された gsk_... から始まるキーをコピーし、左パネルに入力。

ステップ 3: Google Cloud OAuth 2.0 (本番API接続時)

※提出・デモ目的であれば、左側の「デモ (模擬データ)」モードのままでも十分動作を実演可能です。

  1. Google Cloud Console で新規プロジェクトを作成。
  2. APIとサービス > ライブラリ から「Google Drive API」「Google Sheets API」「Google Docs API」「Google Slides API」を有効化。
  3. OAuth同意画面 を設定（アプリ名、ユーザーサポートメールを入力して作成）。
  4. 認証情報 > 認証情報を作成 > OAuth クライアント ID（ウェブアプリケーション）を作成。
  5. 承認済みの JavaScript 生成元に GitHub Pages の URL (https://<username>.github.io) を追加。
  6. クライアントIDをアプリに設定して連携完了！
